  <Card title="Redis lost writes after isolation" icon="seti:db">
      This example demonstrates how a Redis/Sentinel cluster can drop acknowledged writes after isolation.

      This test is based on awesome [article](https://aphyr.com/posts/283-jepsen-redis) by Jepsen that claims up to 56% of lost writes.
      However, during tests, it was only possible to reproduce around 30% of lost writes.

      [Source code](https://github.com/sotnii/pakostii/blob/main/examples/redis_lost_writes)
