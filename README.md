# [![Pakostii](assets/logo.svg)](https://sotnii.github.io/pakostii)

A developer-friendly chaos testing framework for investigating how distributed systems 
behave under all sorts of environment failures (e.g. network partitions).

## ⚠️ HEAVY WORK IN PROGRESS ⚠️
Pakostii is currently under heavy development and is not ready for production use.

## Docs
Docs can be found [here](https://sotnii.github.io/pakostii).
